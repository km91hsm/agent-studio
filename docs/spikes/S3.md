## 3. ADR-0007 재검토 조건 판정

재검토 조건: "공급자 약관이 CLI 로그인 재사용을 **명시적으로 금지**하거나 P00 S3 **실측에서 차단**될 때 → API key 기본으로 전환".

| 공급자 | 명시적 금지? | 실측 차단? | 판정 |
|---|---|---|---|
| OpenAI/Codex | **범위 한정** — 로컬·오픈소스 앱의 app-server 인증 계속 사용은 명시적 허용(O1), "commercial or hosted services"는 **명시적 불허**(같은 문장) | 없음 | **현재 로컬·비상업 전제에서 미발동** — 기본값(CLI 로그인 재사용) 유지. 상업·호스팅 배포는 불허 범위이므로 **배포 전** SIWC 파트너 신청·승인과 인증 경로 확정을 게이트로 둔다(전환 "시점"이 아니라 배포 "전"). SIWC 이전은 현재도 "권장". OpenAI Terms·Usage Policies 원문은 미확인(403)이라 판정은 app-server 문서가 확인해 주는 범위 안에서만 |
| Anthropic/Claude | **두 갈래** — (금지) "제3자 개발자가 자기 앱에 Claude.ai 로그인을 제공·구독 자격증명을 사용자 대신 라우팅·토큰 수집/저장/중개"(A1), "Agent SDK 기반 제품의 claude.ai 로그인·rate limit 제공은 사전 승인 없이는 불허"(A5), Agent SDK 개발자는 API key "should"(A1); (예외) "end user가 **수정되지 않은** Claude Code 바이너리에 **자기** 구독으로 로그인"은 제한 대상이 아님(A2). 조사 노트는 Agent SDK 제품의 구독 로그인 사용을 **회색지대, 보수적으로는 금지 쪽**으로 평가 | 없음 | **갈라서 판정** — (1) 사용자 본인이 로컬에서 자기 설치 CLI를 자기 구독으로 쓰는 **개인 사용**: A2·A6에 기대어 **잠정 미발동**(약관 자문 아님). (2) **공개 배포 제품**으로서의 기본값: Agent Studio가 "자기 제품에서 로그인을 제공"하거나 "사용자 대신 구독 요청을 라우팅"하는지는 토큰 비접촉·무수정 CLI 기동만으로 해소되지 않음 → **미판정·공급자 확인 필요**. 공급자 회신 전에는 예외(A2) 적용을 확정 서술하지 않는다. 회신이 불허이거나 아래 제약을 지킬 수 없으면 발동(API key 기본) |

Claude 측 개인 사용 "잠정 미발동"의 전제이자 공개 배포 판정의 입력이 되는 **설계 제약(ADR-0007 개정 제안, 자동 수정하지 않음 — 제안 상태)**:
1. 앱은 Claude 자격증명·세션 토큰을 읽지·저장하지·중개하지 않는다(현재 S2 러너 구조 그대로 — `pathToClaudeCodeExecutable`로 사용자 설치 바이너리를 기동하고 인증은 CLI가 수행).
2. 로그인은 `claude` 바이너리의 Anthropic 자체 플로우(`claude /login`)로만 완료되며, 앱 UI는 "로그인 안내 → CLI 실행"만 제공하고 **"Claude.ai 로그인"을 제품 기능으로 광고하지 않는다**(A1·A5).
3. 바이너리 무수정, 내장 인증 방식(API key 포함) 제거·제한 금지(A4). 앱은 API key 모드를 항상 1급 선택지로 노출(ADR-0007 기존 결정과 일치).
4. UI에 약관 상태 안내 + "구독 한도·usage credits 차감 가능, 통지 없는 집행 가능"(A3·A6) 고지.
5. 공개 배포(다른 사용자에게 제공) 전 Anthropic contact-sales(Legal 페이지 안내 경로)로 허용 여부 확인 — ADR-0007 "공개 배포 전 사용·재배포 조건 확인 게이트"를 **릴리스 차단 조건**으로 승격. Codex 측은 상업·호스팅 전환 시 SIWC 파트너 절차.

→ **사용자 보고 사항**: ADR-0007은 "ACCEPTED" 유지하되, (1) 위 5개 제약을 "결정" 절에 추가, (2) "결과" 절에 "공개 배포 경로의 Claude 구독 로그인 재사용은 **미판정(공급자 확인 필요)**"을 명시, (3) 재검토 조건에 "공개 배포 전 Anthropic 확인 미완료 / Codex 상업·호스팅 배포 전 SIWC 미승인"을 추가하는 개정을 **제안**한다(P00 종료 게이트에서 사용자 승인 후 적용). 기본값 유지 결정의 책임 주체는 사용자(R21).
